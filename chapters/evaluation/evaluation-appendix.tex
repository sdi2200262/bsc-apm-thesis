\section{Spec-kit Release Audit}
\label{app:evaluation-speckit-audit}

The audit installs each release of the span as a project and diffs each against the next, since Spec-kit renders its templates as it installs them. The compared files are the commands of Section~\ref{sec:evaluation-comparison-framework} together with file templates, scripts, and a context file they instruct the agent to use, each compared byte for byte.

What a change amounts to is a matter of interpretation, since one line can carry a great deal of instruction to an agent. The audit therefore ships a unified diff per release step, alongside a manifest hashing every installed file at every release that ties each diff to the release it comes from.

Six of the eight steps leave the files identical. Of the other two, v0.8.9 cleans up whitespace in three templates, leaving v0.8.6 as the one release to alter what the agent is told, adding a line that directs the implementing agent to reread the project constitution where one exists. Appendix~\ref{app:evaluation-availability} locates the script and its output, where each change can be read in full.

\section{Questionnaire Instrument}
\label{app:evaluation-questionnaire}

The second-session question, ``Compared to the framework you used in your first session, completing the task with this framework felt\ldots'', offers five levels:
\begin{itemize}[nosep]
    \item much harder
    \item harder
    \item about the same
    \item easier
    \item much easier
\end{itemize}
The completion-state question, ``Completion state'', offers four options:
\begin{itemize}[nosep]
    \item Completed the task comfortably within the three-hour cap
    \item Completed the task near the three-hour cap
    \item Hit the three-hour cap without completing
    \item Stopped early without completing
\end{itemize}
The two free-text prompts are:
\begin{itemize}[nosep]
    \item ``What stood out about working with this framework on this task?''
    \item ``Anything else you want to add about this session?''
\end{itemize}

The eight rating items and the wording at each end of their scale are given in Table~\ref{tab:evaluation-questionnaire-items}.
